# Change Requests — maintenance (append-only)

> The inbox for any **structural / major** change (Invariant 6): a contract's I/O, routing, names, moving or
> retiring a room, or bending an Invariant. A human disposes; `modify-workspace` applies an APPROVED CR.
> Append-only — never edit a disposed CR; supersede it with a new one.

## Format
```
### CR-NNN — <title>
- Proposed by: <agent / human>
- Date: <YYYY-MM-DD>
- Problem: <what's wrong / what's needed>
- Proposal: <the concrete change>
- Impact: <what it touches — files, contracts, routing>
- Disposition: PENDING | APPROVED (date) | REJECTED (date) | SUPERSEDED by CR-MMM
```
